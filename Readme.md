# Fieldnotes — Flexbox Landing Page

A simple and responsive outdoor gear landing page created using **HTML5 and CSS3** as part of the Day 7 / Week 7 Flexbox assignment.

## About the Project

Fieldnotes is an outdoor equipment landing page designed to demonstrate CSS Flexbox concepts.

The website includes a navigation bar, hero section, product cards, membership pricing plans, and a login form.

## Features

- Responsive navigation bar.
- Hero section with heading and call-to-action button.
- Product listing with three product cards.
- Membership pricing cards.
- Login form with email and password fields.
- Hover effects on buttons and navigation links.
- Responsive design for mobile devices.

## Technologies Used

- HTML5
- CSS3
- Flexbox

## Flexbox Concepts Covered

1. `display: flex` — Creates flexible layouts.
2. `justify-content` — Aligns items horizontally.
3. `align-items` — Aligns items vertically.
4. `flex-direction` — Changes the direction of flex items.
5. `flex-wrap` — Allows items to move onto new lines.
6. `flex-grow` — Allows items to use available space.
7. `flex-basis` — Defines the initial size of flex items.
8. `gap` — Adds spacing between elements.

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. You can also use Live Server for previewing the website.

**Note:** An internet connection is required to load product images from Unsplash.

The login form is only a frontend demonstration. It does not authenticate users or store information.
